\# Module 3: AI-Generation Detection \& Face Verification



Part of the AI-Based Fake Identity \& Document Screening System.



\## What it does

\- \*\*AI-Generation Detection\*\*: Determines whether a submitted document image was generated by an AI tool rather than being a genuine photograph, using a pretrained vision transformer model combined with a statistical noise-uniformity fallback check.

\- \*\*Face Verification\*\*: Compares the face in the submitted document against a live selfie to confirm identity match, using deep-learning face embeddings (Facenet) with RetinaFace detection.

\- \*\*Tiered Risk Output\*\*: Returns a `PASS` / `REVIEW` / `REJECT` recommendation instead of a raw score, for explainable decision-making.



\## Tech Stack

\- FastAPI (API layer)

\- Hugging Face Transformers — `Ateeqq/ai-vs-human-image-detector`

\- DeepFace (Facenet model, RetinaFace detector)

\- PyTorch, OpenCV, Pillow
